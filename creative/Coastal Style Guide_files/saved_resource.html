Palette

Split three ways. Core is the identity and does not change. Accent holds Cyan and Coral — they carry the mark and its alert state, but they are decoration, not interface. Secondary is proposed this round to give the UI a success, a warning and a highlight without overloading Coral, which currently does error duty and heart duty at once. The tower stripe still resolves per theme — navy in light mode, sky in dark — so it always reads as a second tone against the shield.

02

Mark

"Pulse Beacon" — a pointed-peak shield with the lighthouse cut out as negative space: lantern, beams, and the diagonal tower stripes all knocked out of the sky-blue fill, with a coral heart glowing where the lantern sits. This is the production geometry, round 22 — pulled directly from the logo board.

Coastal Healthcare Advocates

Shield: pointed-peak container, locked since round 11. Lighthouse, beams, and tower stripe are cut from the fill as true negative space — not drawn on top.

Tower: diagonal stripe rebuilt flush with the collar in round 22, no visible seam gap. Heart: positive element glowing in the lantern, geometry unchanged since round 5, now filled coral so it reads as the mark's one warm note against the cool shield. Stripe: as of this round every colourway takes the shield's own tone, so the bands read as shield showing through a cut-out tower rather than as a second colour drawn on it. Tower and stripes are one path, the stripes punched out of it, so the mark is a single stencil at any size.

Wordmark: flat ink fill, no gradient sweep, no spark dot (both dropped round 21–22). Full production file, colourway variants, and favicon set live on the logo board.

Type scale

Every size on this page comes off one modular scale — a base size multiplied by a single consistent ratio — rather than being picked by eye. That is what keeps a long page feeling composed instead of assembled.

1.25
Major third · base 17 px

The standard ratio for modern web work — bolder than the 1.2 minor third often used for premium brands, short of the drama of 1.5. It earns its place here for a specific reason: 1.25 off a 17 px base reproduces the sizes this brand already uses — the 11 px eyebrow, the 17 px body, and the 65 px H1 that tops the scale. The scale was reverse-engineered from the identity rather than imposed on it.

Nine columns

Website layout runs on a 9-column grid. Nine divides cleanly into thirds, which is what most of the site actually needs — three service tiles, a two-thirds article beside a one-third rail — and it keeps the page from drifting into the twelve-column default where every span is available and nothing is decided.

Reference figures below assume a 1000 px content canvas with 24 px gutters, giving a 90 px column.

The measure decides the body span, not the grid. Running text stops at 65 characters regardless of how wide the column is available — the scale governs height, the measure governs width. Five columns is 545 px, which at 17 px sets to roughly 66 characters: almost exactly right. Six columns is 659 px and about 80 characters, already past comfortable. So running text spans 5, never 6, and the remaining four columns are left open rather than filled.

Where this collides with the golden ratio. φ has no clean expression in nine columns. The natural 6/3 split is 0.659, not 0.618 — on a 1000 px canvas that is 659 px against φ's 618 px, off by 41 px. Pick one and be consistent: either let 1.618 govern the outer page shell and run the 9-column grid inside it, or accept 6/3 as the working split and drop φ from the layout entirely. Do not try to satisfy both in the same frame — the columns will not line up.

The scale in use. Note that hierarchy comes from the jumps between steps, not from using every step — this page fragment skips from 65 to 21 to 17, and reads more clearly for it.
