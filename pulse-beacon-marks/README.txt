Coastal Healthcare Advocates - Pulse Beacon mark
================================================

Round 23 geometry. Each SVG is standalone and self-contained: no CSS variables,
no external fonts, colours baked in. Opens cleanly in Illustrator, Figma, Affinity.

The lighthouse, its beams, and the gaps between the tower stripes are TRUE NEGATIVE
SPACE - transparent, so whatever sits behind the mark shows through. Do not fill them.

Artboard: 120 x 132 units.
Clear space: 12 units (10% of mark width) on all four sides.
Minimum size: 20 px wide. Below that, use the favicon cut (mark without beams).
