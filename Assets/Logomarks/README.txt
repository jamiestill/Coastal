COASTAL HEALTHCARE ADVOCATES — lockups
Round 24. Supersedes the round-23 set; delete the old files.

All type is OUTLINED — Tenor Sans and Ysabeau 500. No fonts needed at the printer.
The mark inside every lockup is the round-24 geometry: lighthouse scaled 1.25x, clipped
to the shield, stripes punched out as negative space. See README-marks-note.txt.

FORMS (each in 4 colourways: primary, dark, one-colour, reversed)
  lockup-horizontal-*   mark + rule + stacked wordmark. Default. Min width 180px.
  lockup-stacked-*      mark above centred wordmark. Square placements. Min width 120px.
  wordmark-*            "COASTAL / HEALTHCARE ADVOCATES", no mark. Min width 140px.
  logotype-*            "COASTAL" alone. App headers, tight spaces. Min width 90px.

PNGs at 2048/1024/512px, transparent. Clear space is baked into each artboard.
Reversed is on Paper #F5FBFF (it was pure white in round 23 — white is no longer in
the palette; the knockout takes Paper).
